# RUS-Former: Robotic Ultrasound Scanning for Carotid Artery

![RUS-Former Demo](https://github.com/user-attachments/assets/574bfbc3-2c3b-46c4-a3b9-7a444ed1f76c)

RUS-Former is a Transformer-based visual servo framework for autonomous robotic carotid ultrasound scanning. It integrates carotid artery segmentation with multimodal information, including ultrasound images, probe poses, and contact forces, to achieve end-to-end control from image feature extraction to robotic motion generation.

## Framework

RUS-Former mainly consists of:

- **CAS-Net** for robust carotid artery segmentation and centroid localization.
- **Transformer-based Visual Servo Controller** for multimodal fusion and Cartesian velocity prediction.
